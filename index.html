FAQ

Quick answers before you order.

Do I need Vencord?

For custom CSS Discord themes, yes. Vencord allows custom Discord CSS themes to be applied.

Can you build around my server brand?

Yes. Your colors, logo, server type, audience, theme concept, and reference images can all be used to guide the design.

How do I start an order?

Join the Discord or use the order form. The Discord is best if you want to ask questions first.

Can I request a full visual kit?

Yes. The Full Visual Kit is built for servers that need banners, webhook visuals, theme direction, and full brand support.
