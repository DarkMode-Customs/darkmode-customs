FAQ

Quick answers before you order.

Do I need Vencord?

If you want a custom Discord CSS theme, yes. Vencord is what allows the custom CSS theme to be used properly.

Can you build around my server brand?

Yes. Colors, style direction, logos, reference images, and server type can all be used to guide your custom build.

How do I start an order?

The easiest way is to join the Discord or use the order form. Discord is perfect if you want to ask questions first.

Can I request a full visual kit?

Yes. The Full Visual Kit is for communities that want broader support including banners, webhook visuals, and full server presentation.
