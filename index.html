FAQ

Do I need Vencord?

For custom CSS Discord themes, yes. Vencord is what allows users to apply custom Discord CSS themes.

Can you build around my server brand?

Yes. Colors, logos, community type, and reference images can all be used to create a custom direction.

How do I start an order?

Join the Discord or use the order form. The Discord is best if you want to ask questions first.

Can I request a full visual kit?

Yes. The Full Visual Kit is for banners, webhook visuals, server graphics, and stronger branding support.
