DarkMode Customs™ Secure Admin Gate

Default admin gate password:
DMC-ADMIN-2026!

This password gate hides the admin controls from casual visitors and removes the Admin link from the public website navigation/footer.

Before launch, change the admin gate password hash in script.js:
1. Open your browser console on any HTTPS page.
2. Paste this, replacing YOUR-NEW-PASSWORD:

crypto.subtle.digest('SHA-256', new TextEncoder().encode('YOUR-NEW-PASSWORD')).then(hash => console.log(Array.from(new Uint8Array(hash)).map(b => b.toString(16).padStart(2, '0')).join('')))

3. Copy the generated hash.
4. In script.js, replace the value of ADMIN_PANEL_PASSWORD_HASH with your new hash.

Important:
This front-end lock is not true server-side security because static website files can still be inspected by advanced users.
For real protection, also protect admin.html with Cloudflare Access / Zero Trust or serve admin.html from a password-protected Cloudflare Worker route.
Keep ADMIN_TOKEN enabled in your Cloudflare Worker so unauthorized users cannot post live status changes.
